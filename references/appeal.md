# 自证存证与误判复核

**核心原则：存证要在送检之前做，不要等被判高再补。** 事后补材料既费劲又不可信。

## 一、送你自己的"作者证明"包（送检前建立）

建一个文件夹（建议与论文同目录，命名 `作者证明_不要删除/`），放这些内容。它们的共同作用是把"这篇是你写的"从主张变成可核查的事实。

### 1. 过程文件（最重要）

| 材料 | 说明 | 为什么有用 |
|---|---|---|
| 写作大纲的多个版本 | 包括手写拍照、思维导图、早期提纲 | 显示论证结构是逐步长出来的，不是一次成型 |
| 分章节的早期草稿 | 每个章节至少留 2 个版本 | 版本之间的差异显示真实修改过程 |
| 文献阅读笔记 | 读书笔记、批注截图、摘录 | 证明论据来源 |
| 数据与素材原件 | 实验记录、问卷原始表、访谈录音、代码、Excel | 正文里的数字能追溯到来源 |
| 时间戳证据 | 云盘文档历史版本、Word 修改记录、Git 提交历史 | 第三方时间戳，可信度最高 |

**操作要点**：如果你用飞书/腾讯文档/Notion 写作，**不要关掉版本历史**——这本身就是最好的时间戳证据。用 Word 的话，开启"自动保存到 OneDrive"能保留版本记录。

### 2. 版本与修订记录

导出一次你的修订记录（Word：审阅 → 修订记录；或云文档的版本历史列表），截图或导出 PDF 存档。

**注意**：不要为了存证而刻意制造一堆无意义的版本。真实的版本历史本身就够用，造假的版本历史反而会被看出来。

### 3. 沟通记录

- 与导师讨论选题、提纲、修改意见的聊天记录或邮件
- 与同学讨论的群聊（如有）
- 提交给导师的阶段性稿件及回复

**说明**：涉及他人隐私的内容（他人姓名、联系方式）提交前做适当处理，只保留能证明"这篇论文的写作过程"的部分。

### 4. 素材来源清单

单独一页，列出正文中每个关键数字/案例的来源：
```
第 2 节 1,847 名学生   → 问卷原始数据（附件 survey_raw.xlsx，2025-09 收集）
第 3 节 12.4%          → 国家统计局 2024 年公报，第 7 页
第 4 节 访谈引用        → 访谈录音 03，时间戳 00:12:35
```

这一页在申诉时的作用是：**它证明了正文的具体性来自真实工作，而不是模型生成的填充。**

## 二、申诉流程

### 第一步：确认复核机制

不同主体的流程不同，先问清楚：

| 主体 | 找谁 | 关键问题 |
|---|---|---|
| 课程论文 | 任课教师 → 教学秘书 → 学院教务 | 检测报告是否作为唯一依据？有没有人工复核环节？ |
| 毕业论文 | 导师 → 学院研究生秘书/学位办 | 学校的 AIGC 检测规定原文是什么？阈值多少？超标后的处理流程？ |
| 期刊投稿 | 编辑部 | 是否采信第三方 AIGC 报告？是否接受作者说明？ |

**重要**：已有公开报道提到检测平台方面对质疑表示可以申请复核（[相关报道](https://article.pchome.net/news/14745.html)）。各平台、各学校的具体机制不同，**以你所在单位的正式规定为准**。**先问机制，再准备材料**——不要自己猜流程。

### 第二步：申请复核（而不是继续改稿）

**在被判定有问题后，第一动作是申请复核，不是回去改稿。** 改稿后再送检，等于承认了原来的判定，且新版本失去了过程证据的连续性。

复核申请要点：
- 说明你的写作过程（引用上面的过程文件）
- 提供作者证明包
- 提出具体的复核请求：人工复核、更换检测版本复测、或由专家评审判断
- 语气：陈述事实，不指控平台

### 第三步：申诉说明信模板

```
关于《论文题目》AIGC 检测结果的复核申请

尊敬的 XX 老师 / XX 学院学位办公室：

本人 XXX（学号 XXX），于 XXXX 年 XX 月 XX 日提交的《论文题目》，
在 XX 平台检测中得到 AIGC 率 XX% 的结果。本人对该结果有异议，申请复核。

一、论文写作过程
本文选题于 XXXX 年 XX 月与导师 XXX 讨论确定。XXXX 年 XX 月至 XX 月完成
文献阅读与数据收集，XXXX 年 XX 月完成初稿，经 X 次修改后定稿。
相关过程材料见附件。

二、正文具体内容的来源
本文正文中的全部数据与案例均来自本人实际工作，可追溯来源如下：
1. 第 X 节引用的 XX 数据，来源为 XXX（见附件 X）；
2. 第 X 节的访谈内容，来源为本人于 XXXX 年 XX 月开展的 X 次访谈
   （录音见附件 X）；
3. 第 X 节的 XX 结论，基于 XXX 的原始数据计算得到（计算文件见附件 X）。

三、附件清单
1. 论文写作大纲及修改版本（X 版）
2. 云文档版本历史导出
3. 问卷/实验原始数据
4. 访谈录音及文字稿
5. 与导师的沟通记录
6. 关键数据来源对照表

本人理解 AIGC 检测工具为统计模型，存在一定的误判可能。恳请贵方对本人的
过程材料予以核查，或安排人工复核。

此致
XXX
XXXX 年 XX 月 XX 日
```

**使用这个模板时必须真话实说。** 如果你确实大量使用了 AI 生成正文，就不要声称"全部由本人独立完成"——那会把一个可以处理的学术规范问题变成诚信问题，性质完全不同。

### 第四步：如果复核维持原判

- 要求书面说明判定的具体依据（哪几段、多少比例、依据什么规定）。
- 按学校规定走后续程序（学位办、学术委员会）。
- **不要**在网络上公开指控平台或学校——无助于解决问题。
- **不要**为了下次通过而去做伪装型处理。真正的解法是下一篇论文自己写。

## 三、给用户的最后一句提醒

存证的意义不只是为了申诉。保留写作过程、读过原始文献、跑过真实数据，直接提高的是**你在复核中能够自证的能力**——你可以把每一处论据指回来源。

至于这些做法是否影响检测结果，本 skill 不作预测；它的价值在于让你在需要时拿得出证据。
