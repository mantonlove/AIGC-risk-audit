# 实验与文档偏离记录

## 2026-09-17：规则化编辑补测

早期改写建议按经验排列。随后对 120 对同题摘要建立 A/B/C 规则化编辑，并补做 D（追加通用句）和 E（A+B）条件。A/B/C 初始分数保存在 `out/edit_effects.json`；D/E 另存于回测工程 `out2/edit_probe_ctrl.json` 与 `out2/edit_probe_combined.json`。`tests/measure_edits.py` 的模型重跑入口只覆盖 A/B/C，`--summarize-saved` 可只读复算已存 A–E 分数。实验解释见 `references/edit-effects.md`。

## 2026-09-26：审查后收窄主张

- **A 的操作并非“作者补充真实论据”。** 历史代码从人类摘要抽取数字和术语，尾附于 AI 摘要；未验证语境适配、事实关系或真实论文中的作者修订。A 三模型均值为负，但逐篇分别有 5、12、21 篇升分，不能再称“从不反向”或“唯一有效”。
- **D 不是严格因果分解。** 通用句近似匹配长度，但措辞与内容也变了；A 与 D 的效应比不能证明“一半来自信息、一半来自长度”。
- **C 实际没有拆句。** `measure_edits.py` 和回测工程 `edit_probe.py` 的历史“拆长句”代码没有改变句子边界；该条件主要删了部分连接词。
- **留出阈值分析缺复现元数据。** 旧文档列出的 60/60 拆分未保存样本索引或种子；这些检出率与 p 值不再作为可复现主结论。另一个 2026-09-13 基线有已保存的 dev/heldout 标签，口径不同。
- **两个“百分比”曾被混比。** `d_hello` 的 13.33% 是 120 篇人类摘要中有 16 篇被二元标记的文档误判率；它不能与单篇论文的疑似字数占比 10% 比较。
- **专利证明方案披露，不证明产品部署。** 原文以知网相关专利推出“越流畅越易检出”的确定方向，证据不足；现在仅在 `references/platforms.md` 记载可核查的公开材料。
- **本地分式与平台报告不等价。** 即使都写成“标记字数 / 总字数”，模型、阈值、分段与覆盖范围仍未校准，不能用本机输出预测知网、学习通、PaperPass 或维普百分比。
- **复现入口修复。** 回测工程 `harness/finalize.py` 现在解包 `calibrate_threshold()` 的 `(threshold, status)`，并在校准失败时停止该模型评估；复现摘要不再把文档误判率拿来判断单篇“10% 线”。
- **历史基线与新评分代码不可直接比较。** 2026-09-13 的 `FINAL_MEASURED.json` 来自旧的长段截断实现；当前检测器代码改为长文分窗覆盖。新跑的 `finalize.py --out out/FINAL_MEASURED_current.json` 写入独立文件，结果属于新的评分口径。
- **存证只能提供核查线索。** 原申诉文档把材料清单、文件时间和哈希描述成作者身份或提交时间的证明，现改为说明各自可核查的范围，并要求按具体服务记录与单位规则判断。

以上修订没有重训模型，也没有取得商业平台的直接配对送检结果；它们改变的是现有资料能支持的结论范围。
