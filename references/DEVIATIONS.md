## 2026-09-17 · 改写优先级重排（P1↔P3）

**原状**：`references/rewrite-rules.md` 的优先级顺序为
P0 清理 → P1 补具体性 → P2 补作者立场 → P3 改节奏 → P4 换术语 → P5 补引语。
该顺序是**按经验排的**，且在 `measured-baseline.md` 里明确声明
"改写建议尚未经过能否降低检测分数的验证"。

**改动**：改为
P0-a 清理 → **P0-b 补具体性（事实锚定）** → P1 补作者立场（标注"不降分"）
→ P2 改节奏（标注"不改变检出分数"）→ P3 换术语 → P4 补引语。

**原因**：完成了原先未完成的改写实验。

**证据**：`references/edit-effects.md`；原始数据 `out/edit_effects.json`；
复现脚本 `tests/measure_edits.py`。n=120 对，3 检测器，配对差 + bootstrap CI + McNemar。

**关键数字**：
- 事实锚定：三检测器 Δ 全为负，符号一致 59–71% → 可用
- 自我设限：d_hello −0.263 但 d_cmj **+0.069**（p=0.0078）、d_zhv3 **+0.046** → 反噬
- 只调节奏：|Δ| ≤ 0.03，符号一致 31% → 噪声

## 2026-09-17 · 新增 anchor.py（事实锚定工具）

**原因**：实测显示"补真实信息"是唯一有支持的动作，但原 skill 只有散文建议，
没有可执行入口，也无法核对用户改完之后具体性有没有提高。

**改动**：新增 `scripts/anchor.py` + `tests/regression.py`（24 条）+ `tests/mutation.py`
（13 处突变，100% 覆盖）。

**边界**：该脚本只**列出**待补真实信息的位置，不生成内容 —— 编造数据/文献是学术不端，
比高 AIGC 率严重。

## 2026-09-17 · 检测器相关性的表述修正

**原状**：文档中出现"多个检测器"的说法，读者容易理解为独立证据。

**改动**：统一改为"N 个**中度相关**的检测器"，并在 `reduce_aigc.py` 的 docstring
里写明 corr(d_cmj, d_zhv3)=+0.928。

**证据**：`out/edit_effects.json` 中 AI 原样组的文档级分数相关矩阵。

## 2026-09-17 · 自查更正三处（写完当天发现的）

审核工具（Codex 子代理）连续两次因配额限制失败，改为自查，发现三处问题：

| # | 问题 | 更正 |
|---|---|---|
| 1 | **McNemar 计数与 p 值抄错**（初稿写 23/0、31/0、8、4） | 实为 **24/0、34/0、12、13**；p 值更强（1.2e−7 / 1.2e−10 / 4.9e−4 / 2.4e−4）。**结论方向不变，证据更强** |
| 2 | **5% FPR 口径是样本内的**：阈值与评估都用同一批 120 篇人类文本 | 改为**对半**（60 定阈值 / 60 评 FPR）。heldout FPR 实为 **2%~12%**（不是 5%）。**"校准到 5%"做不到**，与 measured-baseline 一致 |
| 3 | **A 与 B 都追加了句子**，未分离"补信息"与"追加动作" | 新增**对照条件 D**（长度相当、零信息的通用句）。d_hello 上 D 降 0.092 vs A 降 0.191 → **一半效应来自追加本身** |

**教训**：效应量结论在没有"同等长度的零信息对照"之前是不成立的。
本项目的另一个 skill（claim-gate）也栽在同一类问题上——
**检查了形式，没检查依据**。这次是"检查了编辑，没检查编辑的对照组"。
