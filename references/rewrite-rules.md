# 改写规则（按收益排序）与反模式

## 一、执行原则

**唯一目标：让每一句都真实、具体、可核查。**

不是"让文本像人写的"。这两者的区别在改写过程中会不断显现：

- 如果一句话改完之后，你对它的依据更清楚了 → 改对了。
- 如果一句话改完之后，你也说不清它到底想说啥，只是"读起来不像 AI 了" → 改错了，退回去删掉。

## 二、优先级顺序（**按实测效应排序**，不是按经验）

⚠️ **2026-09-17 更新**：本节顺序已按 `references/edit-effects.md` 的实测结果重排。
实测方法：120 对同题文本（人类摘要 vs 其 AI 版本），三类规则化编辑，
3 个开源中文检测器，配对差 + bootstrap CI + McNemar。

| 原顺序 | 实测结论 | 新位置 |
|---|---|---|
| P1 补具体性 | **唯一在三检测器上都不反噬的编辑**（Δ 全负，符号一致 59–71%） | **升为 P0** |
| P2 补作者立场 | `d_hello` −0.263，但 `d_cmj` **+0.069**、`d_zhv3` **+0.046**，符号一致仅 8% | 保留为**质量项**，**明令不得当降分手段** |
| P3 改节奏 | \|Δ\| ≤ 0.03，检出率变化 ≤ 2.5pp，符号一致 31% | 降为**可读性调整**，**明示不改变检出分数** |
| P0 清理 | 未测（占位符/格式伪影在语料里不存在，无法测） | 保留（它解决的是"生成痕迹"，不是统计特征） |
| P4 换术语 / P5 补引语 | 未单独测 | 保留，归入"事实锚定"家族 |

**一句话**：**只有"补真实信息"这一件事，有实测支持它能降低检出分数。**

### 排序（现行）

### P0-a：清理（5 分钟，必做）

| 动作 | 检查方式 |
|---|---|
| 删所有占位符（`[待补]`、`XX大学`、`20XX年`） | `diagnose.py` 的"占位符残留"项 |
| 清 markdown 残留（`##`、`**`、`-`、表格竖线、代码围栏） | "格式伪影"项 |
| 清零宽字符 | "格式伪影"项 |
| 统一标点（中英文引号、逗号不混用） | 目视 |

P0 不解决"像不像 AI"的问题，它解决的是"有没有生成痕迹"的问题——后者更容易被判死。

### P0-b：补具体性 —— 事实锚定（**实测第一优先**）

对 `diagnose.py` 报的空泛指代逐处处理。**每一处只有两个合法出路**：

1. **换成具体**：作者+年份+样本量+具体结论。
2. **删掉或降级**：改成"本文未找到直接实证"。

没有第三条路。**不能编。**

若用户的某处论据查不到来源，标准回复是：

> 这处目前没有依据。要么找到原始文献补上，要么删掉。如果我替你编一个作者和年份，那不是降 AI 率的问题，是学术不端——而且编造的文献比高 AI 率更容易被发现。

### P1：补作者立场（**质量提升明显，但不降分**）

全文找出至少 5 处加真实的第一人称判断：

- 方法选择理由
- 自我设限（样本、数据、方法局限）
- 与预期不符的发现
- 未解决的问题

⚠️ **实测警告（2026-09-17）**：这一项在 `d_hello` 上降低分数（−0.263），
但在 `d_cmj` 上**提高** 0.069、`d_zhv3` 上**提高** 0.046（都是 95% CI 不含 0）。
三检测器符号一致率只有 **8%** —— 也就是说它在不同检测器上方向近乎随机。

**所以：做它，因为它是好的学术写作；不要做它，以为它能降分。**
如果有人告诉你"加几句自我设限就能降 AI 率"，那是把其中一个检测器的结果当成了普遍规律。

参考句式（**必须是真话**）：
- "本文选择……而非……，主要原因是……"
- "受限于可获得的数据，本文只能……"
- "这一结果与第 X 节的预期不符。可能的解释有两个：……"
- "该机制本文未能验证。"
- "必须承认，本文的样本偏向……"

### P2：改节奏（**可读性调整，不改变检出分数**）

| 项 | 动作 |
|---|---|
| 句长 CV < 0.30 | 每 3-4 句插一个 8-15 字短句；拆超长句 |
| 段落 CV < 0.28 | 判断句/过渡句单独成段；案例段展开到 8-10 句 |
| 连接词覆盖 > 55% | 删掉一半，改由内容逻辑衔接 |
| 句首重复 ≥ 4 次 | 换起句句式 |

⚠️ **实测警告（2026-09-17）**：这一整类编辑（拆句、删连接词）的效应是
|Δ| ≤ 0.03、检出率变化 ≤ 2.5 个百分点、三检测器符号一致率 31%。
**它不改变检出分数。** 想做可读性调整就做，但不要把它列进"降分步骤"——
那会让人以为改了这些就安全了。

**如果用户问"改节奏能不能降分"，标准回答**：
> 实测不能。拆长句、删连接词这类改动，在三个检测器上的分数变化都在 ±0.03 以内，
> 方向还不一致。真正有效的是补真实信息 —— 但那也是因为它让论据站得住，
> 不是因为它"像人写的"。

### P3：换术语

把"赋能/抓手/闭环/生态/痛点/顶层设计"逐个替换为学科内既有术语。这一项通常能顺带提升论文的专业度。

### P4：补直接引语

关键论据处引原话 + 页码。直接引语是极难被统计模型预测的内容。

## 三、反模式（明确禁止，遇到用户要求要拒绝并说明）

| 反模式 | 为什么不做 |
|---|---|
| 中英互译来回倒 | 严重破坏学术表达（术语被翻坏、逻辑连接变形）；检测器早已适配这一套路 |
| 同义词硬替换 | 破坏术语准确性；异常的用词分布本身就是特征 |
| 故意加错别字、拆词 | 会被当作异常特征；且直接降低论文质量 |
| 零宽字符、隐藏文本、白色字体 | 多数平台会清洗；且属于明确的学术不端行为 |
| 正文转图片 | 直接违反格式要求，且是典型的规避行为 |
| 用"降低 AI 率"提示词让另一个模型重写 | 只是把 A 模型的指纹换成 B 模型的；且用户对结果更没把握 |
| 拼接多篇 AI 输出 | 风格断层、术语不一致，通常比单篇更容易被识别 |
| 为压分反复送检、按分数反向拟合 | 反复送检本身是行为痕迹；且"针对检测器优化"在性质上已不是正常写作 |
| 编造数据、文献、访谈、实验 | 学术不端，比高 AI 率严重得多 |

**遇到用户主动要求上述任一项时的标准回应：**

> 这个做法我不建议，原因是 X。而且它解决不了你的问题——检测器测的是统计规律，不是找特定的字。本 skill 能做的是提高文本的可核查性与写作质量，并帮你把过程证据整理成申诉材料；对检测分数的变化方向，我没有依据作预测。你手上有哪些真实的材料？我们从那里开始。

然后立刻给出替代路径，不要说教超过三句。

## 四、改写质量标准（交付前自检）

改完后逐条过：

- [ ] 随机抽 5 句，问"这句的依据是什么"——答不上来的删掉。
- [ ] 全文找不出任何"某高校/有学者/业内人士"。
- [ ] 至少 5 处真实的自我设限或第一人称判断。
- [ ] 找不出任何 markdown 残留、占位符、零宽字符。
- [ ] 数字、年份、样本量、文献页码都能对应到真实来源。
- [ ] 通读一遍：读起来像你自己在讲这件事，而不是像在表演学术写作。
- [ ] **最重要**：如果导师问"这一段为什么这么写"，你能当场答上来。

最后一条答不上来，说明这段本来就不该由 AI 来写。

## 五、给用户的收尾话术

改写完成后，明确告知：

> 改完了。这些改动提升的是论文本身的质量——论据更实、立场更明确、结构有起伏。
>
> 但我必须再讲一次：这**不保证**任何平台的检测结果。各平台的阈值是内部参数，而且会随版本变化。纯人类写作被判高 AI 率的公开案例有很多。
>
> 所以下一步按 `appeal.md` 把过程材料存好，然后送检。如果被判高，走复核，不要再改稿压分。
