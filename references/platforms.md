# 商业 AIGC 检测平台：公开证据与解释边界

## 已核实的公开材料

| 来源 | 能支持的说法 | 不能据此推出的说法 |
|---|---|---|
| [知网毕业论文（设计）管理系统 AIGC 检测服务体验协议](https://co2.cnki.net/User/AIGCAgreement.html) | 协议写明结果由 AI 模型生成，可能漏检或误检，仅供参考；其中的 AIGC 值表示文章内容存在 AI 生成的概率大小，与文章质量无关。 | 该协议没有公开可供本地工具复刻的模型、分段、阈值或概率校准细节。 |
| [CN117033555B](https://patents.google.com/patent/CN117033555B/zh) | 同方知网相关主体披露了用多模型 token 表合成训练语料、再做分段 token 分类统计的方案。 | 专利不证明现网部署，也不能将某些 token 当作线上固定触发词。 |
| [CN117151074B](https://patents.google.com/patent/CN117151074B/zh) | 同方知网相关主体公开了一种融合分类概率、偏离度、扩散度、句长和字词分布的专利方案。 | 获得专利不证明现行检测服务部署了该方案，也不证明其中某个特征可被单独控制。 |
| [CN119357388B](https://patents.google.com/patent/CN119357388B/zh) | 同方知网相关主体公开了将原文与改写文本的信息量差用于判断的专利方案。 | 不能推出“写得更流畅一定更可疑”“补数字一定降分”，也不能把专利方法当作现行产品说明书。 |

此前文档声称记录了“前端 bundle 提取的一手机制”，但未保存可核验的提取记录；因此本文件不再据此描述平台内部实现。维普、PaperPass、学习通／大雅的当前 AIGC 检测模型、阈值和分段规则，在本项目现有材料中均没有足够的一手证据。不能凭这些平台的查重语料、产品定位或用户反馈推断它们对某种文风更敏感。

## 解读用户报告时先确认口径

同一份文稿在不同平台上出现不同数值，可能涉及模型、报告字段、版本、预处理或切片差异；这些是**可能原因**，不是已核实的各平台参数。先记录：平台与报告日期、送检文稿的版本、检测范围、报告字段名称、学校或期刊的现行规则。若用户有完整报告，直接解释报告中的定义；没有定义时不要自行把“AI 率”解释为某个特定公式。

本地 `score_text.py` 输出两种聚合信息：开源模型的段落分数字数加权平均，以及按本地阈值标记段落后得到的字数占比。后者形式上可写成“标记字数 / 纳入计算字数”，但商业平台的模型分数、阈值、分段和纳入范围未校准。默认 `--threshold 0.5` 是本地展示参数，**不是任何商业平台的已知阈值**；本地占比不是商业报告的百分比预测。

同理，`references/measured-baseline.md` 中的 13.33% 是“120 篇人类摘要有 16 篇被本地检测器二元标记”的**文档误判率**。它不能与某一篇论文报告的“疑似字数占比 10%”比较，也不能换算出商业平台误判率。

## 实务处理

出现原创误判争议时，保存报告对应的原稿、报告日期、草稿历史、资料来源和实验或访谈记录；按学校或平台现行规则申请人工复核。过程材料用于说明作者如何形成论证，文件修改时间和哈希只能作为版本核对线索，不能独立证明创作时间。

不要承诺“针对知网／学习通／PaperPass 稳定达标”。如果要声称某编辑对某平台有效，必须有该平台、该版本、该语料和同一报告口径下的直接观测，并说明样本与不确定性；当前项目没有这组数据。
