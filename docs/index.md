## 一句话结论

在这批本地检测器上，**"降分"是可实现的，但那不证明文本更像人写**：
同剂量的随机字符替换降得比任何词表都多，而任何大模型重写都会把分数推高 0.24–0.30。
真正站得住的方向只有两个——只改贴线的少数段落，以及让作者补真实依据。

本文档中的所有数字均为**本地开源检测器**的输出，与商业平台的百分比没有校准关系，不构成任何平台的达标承诺。
